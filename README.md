An entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) "Fortune Cookie Funnies for Engineers" bounty. `main.ts` (Node 22, standard library only) writes one fortune cookie message for a software engineer to `/output/entry.txt`:

> Your code compiles; the tests just filed a restraining order.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
